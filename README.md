# Babu Studios

Cinematic, scroll-driven 3D website for Babu Studios. Next.js (App Router) + React Three Fiber.

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run typecheck`, `npm run lint`, `npm run palettes`.

Project decisions, architecture rules, palette tokens and phase status live in [`CLAUDE.md`](./CLAUDE.md).
